# Состояние проекта

Короткая сводка по репозиторию. Обновляется вручную, без автоматики.

## Что лежит где

| Путь | Содержимое |
| --- | --- |
| `apps/web` | веб-клиент, vanilla ES modules |
| `apps/android` | Android-приложение, Kotlin + Compose |
| `apps/code-android` | Clauden Code для Android |
| `apps/desktop` | десктоп-клиент, Electron |
| `apps/code-desktop` | Clauden Code для десктопа |
| `backend` | HTTP-шлюз: аккаунты, тарифы, чаты, оплата |
| `docs` | архитектура, API, развёртывание |

## Готово

- клиенты и шлюз выложены в открытый доступ;
- в шлюзе работает пул ключей с автоматическим переключением при отказе;
- есть сквозной тест оплаты и отказоустойчивости;
- описаны развёртывание и самостоятельный хостинг (`docs/SELF-HOST.md`).
