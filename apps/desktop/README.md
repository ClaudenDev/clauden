# Clauden Desktop (Electron)

ПК-версия Clauden с тремя провайдерами в одном интерфейсе:

| Провайдер | Куда идут запросы | Cookie / ключ | Тариф |
|---|---|---|---|
| **Claude** | напрямую в `claude.ai` с вашего компьютера | только на ПК, в профиле Chromium | ваш аккаунт Claude |
| **Clauden** | шлюз Clauden (`/v1`) | сессия Clauden | Pro / Max / Ultra |
| **Свой API** | выбранный OpenAI-совместимый сервис | ключ только на ПК (`safeStorage`) | тариф провайдера |

Интерфейс — тот же, что у веб-версии: приложение загружает его из сети,
поэтому обновляется вместе с сайтом. Если сети нет, показывается локальная
страница «нет связи» с кнопкой повтора.

## Структура

```
src/main/main.js      окно, меню, протокол clauden://, апдейты
src/renderer/         интерфейс (статика из веб-версии)
claude-client.js      мост к официальному Claude-аккаунту
assets/               иконки и ресурсы
```

## Сборка

```bash
npm ci
npm run dist:win     # NSIS x64
npm run dist:linux   # AppImage, deb
npm run dist:mac     # zip, x64 + arm64
```

Или запуск из исходников:

```bash
npm start
```

Сборка без подписи кода работает локально; для распространения нужен свой
сертификат и свой канал обновлений (`publish` в `electron-builder.yml`).

## Два режима

- **Claude** — запросы идут с вашего компьютера в `claude.ai`, cookie лежат
  только в профиле Electron.
- **Clauden** — запросы идут на шлюз, тариф проверяется там же.

Переключение — в настройках, без перезапуска.

## Ресурсы прокси

Бинарники xray (`resources/xray/<platform>`) в репозиторий не входят: это
сторонние сборки большого размера. Без них приложение собирается и работает,
но раздел прокси сообщает, что локальный туннель недоступен. Чтобы включить
его, положите ядро в `resources/xray/linux-x64`, `win-x64` или `mac-*` перед
сборкой.
