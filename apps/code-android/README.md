# Clauden Code для Android

Отдельное приложение для агентных сессий Clauden. Не трогает основное
приложение: свой пакет, свой вход, свой интерфейс.

## Два режима

| Режим | Где работает агент | Что нужно |
|---|---|---|
| **Телефон** | сессии на шлюзе Clauden (`/v1/code/*`) | аккаунт Clauden с платным тарифом |
| **SSH** | ваш собственный сервер | SSH-хост, ключ или пароль |

В режиме «Телефон» файлы и команды живут в рабочей папке сессии на сервере.
В режиме SSH сессия поднимается на вашей машине, а приложение только
показывает транскрипт и отправляет ввод.

## Интерфейс

- почти чёрный фон, графитовые карточки, тёплый оранжевый Claude;
- шрифт Geist Mono с настоящей жирностью;
- главный экран: шапка с логотипом, переключатель Телефон/SSH, карточка
  текущего проекта, статус агента, последние сессии, композер;
- экран сессии: шапка с состоянием, лента в стиле Claude, карточки
  инструментов с раскрытием, Markdown, индикатор печати;
- шторки: меню главной, меню сессии, проект, сессии, SSH-серверы.

Ключевые файлы:

| Файл | Что |
|---|---|
| `ui/IdeApp.kt` | корень: boot → login → paywall/IDE, SSE, слэш-команды |
| `ui/Welcome.kt` | главный экран |
| `ui/Session.kt` | экран сессии, аппрувы и формы, композер |
| `ui/Transcript.kt` | блоки транскрипта, карточки инструментов, Markdown |
| `data/CodeApi.kt` | HTTP к `/v1/code/*` |
| `service/AgentRunnerService.kt` | фоновая сессия |

## Сборка

```bash
./gradlew assembleRelease
```

JDK 17, Android SDK 35. Адрес шлюза — `CLAUDEN_BASE_URL` в
`local.properties` (`clauden.baseUrl`).

## Оплата и доступ

Code доступен на Pro, Max и Ultra. Если тарифа нет, приложение показывает
экран оплаты и не пускает в сессии. Тариф проверяется на шлюзе при каждом
запросе, поэтому обойти экран оплаты в клиенте бесполезно.
