# Clauden Web

Веб-клиент Clauden. Чистые ES-модули, без сборки и фреймворков: браузер
загружает `js/app.bundle.js` (собранный вход) и модули из `js/`.

## Структура

```
index.html          каркас приложения
css/                стили: приложение, лендинг, документация, статус
js/api.js           HTTP-клиент: запросы, SSE, вложения
js/app.js           роутинг, вход, онбординг, лендинг
js/chat.js          чат: стрим, шаги, артефакты, вложения
js/code.js          Clauden Code
js/settings.js      настройки, тарифы, оплата, usage, API-ключи
js/remote.js        Remote Control по ссылке
js/store.js         IndexedDB: локальные копии чатов
js/markdown.js      рендер ответов
legal/              условия, приватность, оплата
docs/               страница документации
```

## Запуск

Клиент обращается к `/v1/...` на том же origin, поэтому нужен сервер, который
отдаёт статику и проксирует API. Для локальной разработки:

```bash
python3 -m http.server 8080
```

и реверс-прокси на шлюз (`backend/deploy/nginx.conf`).

## Особенности

- SSE-стрим с восстановлением: если соединение оборвалось, клиент забирает
  готовый ответ через журнал ходов.
- Офлайн-режим: чаты и проекты лежат в IndexedDB, синхронизируются при
  появлении сети.
- PWA: manifest и service worker, установка на домашний экран.
- Тёмная и светлая темы, адаптивная вёрстка до мобильных экранов.
