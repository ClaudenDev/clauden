# Clauden Code — десктопная IDE

Приложение для агентных сессий Clauden: дерево файлов, редактор с подсветкой,
диффы с коммитом, чат агента и локальный терминал в одном окне.

## Площадки сессии

- **Этот компьютер** (по умолчанию) — агент работает с папкой на вашей машине:
  файлы читаются и пишутся на диске, команды выполняет приложение. На сервер
  уходит только переписка.
- **Сервер Clauden** — сессия в рабочей папке на шлюзе.

Терминал локальный: команды выполняются на вашей машине. Оболочка —
Git Bash → PowerShell → cmd, вывод в UTF-8 с запасным декодированием
cp1251/cp866.

## Remote Control

Ссылка на текущую сессию: `https://clauden.best/r/<token>`. Открывается в
браузере без входа: видно транскрипт, можно отправить сообщение, остановить
ответ и ответить на запрос разрешения. Ссылка отзывается в один клик.

## Структура

```
src/main/       окно, IPC, локальные сессии, git, файлы
src/renderer/   интерфейс IDE
app.js          точка входа рендерера
chat.js         лента агента и стрим
```

## Сборка

```bash
npm ci
npm run dist:win
npm run dist:linux
```

Запуск из исходников:

```bash
npm start
```

## Требования

- Аккаунт Clauden с тарифом Pro или выше.
- Git в PATH (для диффов и коммитов).
- Node.js нужен только для сборки; в собранном приложении он не требуется.

## Ограничения сборки

Приложение не содержит бинарников прокси и требует Git в PATH. Публикация
обновлений идёт через ваш канал (`publish` в `electron-builder.yml`); при
локальной сборке апдейтер просто не находит новых версий.
