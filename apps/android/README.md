# Clauden для Android

Android-клиент Clauden: Compose-интерфейс в стиле Claude, свой сетевой слой,
полная поддержка чатов, проектов, памяти и Clauden Code.

## Что внутри

```
app/src/main/java/space/teleopen/clauden/
  data/      AuthApi, GatewayApi, CodeApi, модели данных, настройки
  ui/        экраны: чат, Code, настройки, темы, оплата, вход
  proxy/     встроенный клиент для обхода блокировок
  alarm/     отложенные запросы
```

Приложение не содержит кода Anthropic. Интерфейс написан с нуля на дизайн-
токенах, близких к оригинальному приложению.

## Провайдеры

| Провайдер | Куда идут запросы | Ключ |
|---|---|---|
| **Clauden** | шлюз Clauden (`/v1/chat/completions`, SSE) | аккаунт Clauden |
| **Anthropic** | `https://api.anthropic.com` | свой `sk-ant-…` |
| **Свой API** | любой OpenAI-совместимый сервер | свой ключ |

По умолчанию — Clauden. Адрес шлюза вшивается при сборке и меняется в
настройках («Аккаунт → Base URL»).

## Сборка

```bash
./gradlew assembleRelease
# app/build/outputs/apk/release/
```

Требуется JDK 17 и Android SDK 35. Адрес шлюза:

```properties
# local.properties
clauden.baseUrl=https://clauden.best
clauden.apiKey=
```

Пустое поле = значение по умолчанию. Подпись настраивается своим keystore
через `signingConfigs`; ключей в репозитории нет.

## Вход

- **Google** — Credential Manager; id_token проверяется на сервере шлюза.
  Для нативной кнопки в Google Cloud нужен Android-клиент с пакетом
  `space.teleopen.clauden` и SHA-1 сборки.
- **Email** — код из письма. Если Google на телефоне недоступен, приложение
  открывает вход в браузере и возвращается по `clauden://auth`.

Сессия хранится в приватных SharedPreferences; чаты и проекты — отдельным
файлом на каждый аккаунт (`chats-<id>.json`). «Выйти» отзывает токен на
сервере, локальная история остаётся.

## Экраны

- Чат: стрим, размышления, шаги, вложения, артефакты, остановка ответа.
- Проекты и память: инструкции, файлы, синхронизация между устройствами.
- Code: сессии на сервере и по SSH, диффы, файлы, терминал.
- Настройки: темы, тарифы и оплата, usage, API-ключи, устройства.
