# Участие

Спасибо, что заглянули. Правила простые.

## Ветки и коммиты

- `main` — рабочая ветка, всегда собирается.
- Ветка на задачу: `feat/кратко`, `fix/кратко`.
- Коммит: `область: что сделано` — `web: не терять черновик при обрыве`.

## Стиль

- Код без зависимостей, если можно обойтись стандартной библиотекой.
- Комментарии — по делу, на русском или английском, как в файле.
- Форматирование: 2 пробела, ширина 100, `prettier` для JS.
- Kotlin — официальный стиль JetBrains.

## Проверки перед PR

```bash
cd backend && npm test && npm run smoke
node --check src/*.mjs
```

Для клиентов — проект собирается той командой, что в README. Если сборка
не проходит из-за отсутствующего SDK, укажите это в PR.

## Что принимается

- Исправления поведения, воспроизводимые без вашего аккаунта.
- Улучшения доступности и производительности.
- Новые провайдеры оплаты — по контракту `billing.mjs`.
- Документация и переводы.

## Что не принимается

- Изменения, ломающие совместимость протокола без обсуждения.
- Скрытая телеметрия и сетевые вызовы без согласия пользователя.
- Код, который исполняет команды на сервере по умолчанию.

## Процесс

1. Issue с описанием проблемы.
2. PR со ссылкой на issue.
3. Ревью, CI, merge.

Участие означает согласие с [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
